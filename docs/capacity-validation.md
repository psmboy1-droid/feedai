# 피드맨 동시 이용 개선 / 2026-10-12

## 배포 기본값

- RSS 공유 캐시: D1 영속 저장, 성공 5분 / 오류 30초. 서버 인스턴스의 hot cache 60초, 동일 인스턴스의 중복 요청 결합. DB 수집 잠금은 60초 후 회수. 캐시 응답에도 최근 48시간 필터 재적용.
- RSS 새 수집 중: 최근 성공 결과가 있으면 최대 30분간 이전 결과 사용. 최초 수집 결과를 아직 확보하지 못한 요청은 잠시 기다리고 Retry-After와 503을 반환할 수 있음.
- 브라우저 RSS 수집: 최대 6개씩 실행.
- AI: 요약과 기사 분석이 동일한 D1 대기열/한도 공유. FIFO, 대기 최대 1,000개, 계정당 대기/실행 요청 최대 2개.
- AI_MAX_CONCURRENT: 기본 10, 최대 100. AI_STARTS_PER_MINUTE: 기본 20, 최대 1,000. 값은 실제 OpenAI 계정의 RPM/TPM과 비용에 맞춰 낮추거나 조정해야 함.
- AI 신규 시작: 접수 응답 후 서버 background 작업과 분석 상태 조회가 대기열을 처리. 운영자와 회원이 모두 닫은 동안에도 대기열을 계속 소비하는 별도 스케줄러는 연결하지 않았음. 진행 중 작업의 실제 생성은 OpenAI background 요청이 수행하고 다음 상태 조회에서 결과를 동기화함.
- 생성 상태는 서버에서 최소 15초 간격으로 OpenAI에 확인. 브라우저는 5초에서 최대 30초(+분산 지연 0~2초)로 조회 간격 증가.
- 외부 접수 성공 여부가 불명확한 시간 초과는 자동 재접수하지 않음. 30분 후 사용자에게 실패를 반환하되 전체 실행 슬롯은 uncertain으로 보존. 관리자가 공급자 작업 상태를 확인해 슬롯을 정리해야 함. 한도보다 더 많은 작업을 숨겨 실행하지 않는 보수적인 정책.
- 대기 요청은 1시간 후 만료. 끝난 대기열 기록은 7일 후 최대 20개씩 정리. 회원 소유 기록과 연결되지 않은 요청은 실행하지 않음.
- 실패/대기열 초과 시 기존 원자적 토큰 반환 로직 적용. 한 요청의 중복 반환 방지.
- 일반 계정 조회는 프로필 변경/신규 가입 때만 쓰기. 토큰 잔액 조회는 기존 회원이면 한 쿼리. 기사 분석 응답의 tokens를 UI에 직접 적용하여 중복 잔액 조회 제거.
- 계정 저장: feeds/saved/read 중 변경된 필드만 전송하고 SQL json_set으로 부분 갱신. 낙관적 revision 충돌 검사는 유지. DB는 단일 JSON 컬럼을 유지하므로 물리적인 저장량/쓰기 전체가 사라지는 것은 아님.

## 별도 로컬 검증

운영 사이트/운영 DB/실제 OpenAI에 부하를 보내지 않음. 독립 메모리 SQLite에 전체 마이그레이션을 적용하고 실제 feed handler, shared cache, AI queue, token 함수의 코드를 호출. 외부 RSS는 기사 1개/5ms 응답, OpenAI는 mock. HTTP 네트워크/Cloudflare dispatch/실제 D1 분산 지연/브라우저 렌더링은 포함하지 않음.

| 같은 RSS 최초 동시 요청 | 외부 수집 | 오류 | p95 handler 처리 시간 | SQLite 쿼리 누적 시간 |
|---:|---:|---:|---:|---:|
| 100 | 1 | 0 | 20ms | 0.40ms |
| 1,000 | 1 | 0 | 41ms | 0.32ms |
| 10,000 | 1 | 0 | 326ms | 0.43ms |

시간은 개발 머신의 한 실행에서 측정한 값이며 운영 처리량 예측값이 아님. 기사 70개/사용자별 다른 구독/DB 쓰기/실제 AI를 포함한 혼합 시나리오로 1만 동시 접속을 인증하지 않았음.

추가 assertion: 서로 다른 cache module 인스턴스에서도 RSS 수집 1회; 활성 AI 10개 상한; 60초 내 시작 20개 상한과 다음 창 재개; 다른 계정 작업 조회 거절; 동시 토큰 반환 1회; 부분 JSON 갱신에서 구독 필드 보존.

재현: Node.js 24, 프로젝트 루트에서 아래 실행. TS 소스를 런타임에 읽는 테스트 전용 loader이며 배포 코드에는 사용하지 않음.

```
node --experimental-strip-types --loader ./scripts/capacity-check/cloudflare-loader.mjs ./scripts/capacity-check/verify.mjs
```

배포 전 TypeScript 검사와 production build 확인. 실제 D1/외부 서비스까지 포함한 별도 호스팅 부하 시험 및 해당 계정의 정확한 공급자 한도 확인은 미실시. 이 변경만으로 1만 명 무오류를 보장하지 않음.
