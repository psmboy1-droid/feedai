# 도파민 센터

- 공개 페이지: `/dopamine` / 관리자: `/admin/dopamine`.
- 상단 ‘도파민 센터’와 관리자 홈에서 연결됨. 한국·미국·일본별 피드 관리.
- 공식 YouTube 채널/재생목록 RSS 및 `/channel/UC…` 주소 지원. @핸들 주소는 채널 ID가 포함된 RSS로 등록.
- 관리자만 등록/수정/숨김/삭제/강제 수집 및 영상별 분류 수정 가능. API도 관리자·동일 Origin 검증. 수정/삭제에 revision 검사.
- 자동 분류는 RSS의 `/shorts/` 링크 또는 제목의 `#Shorts`/`#쇼츠` 표시 기준. RSS에 구분 정보가 없으면 일반 영상으로 취급. 길이·화면 비율은 RSS만으로 확인할 수 없으므로 완벽한 Shorts 판별을 보장하지 않음. 관리자에서 피드 유형을 지정하거나 개별 영상의 분류를 교정할 수 있으며, 개별 교정은 다음 갱신 후에도 유지됨.
- 쇼츠 3개 한 줄 → 일반 영상 3개 한 줄을 반복. 최신순, 영상 ID 중복 제거, 더 보기. 부족한 칸은 빈 상태로 표시하고 임의 영상으로 채우지 않음.
- 카드 클릭 시 단일 YouTube 개인정보 보호 강화 iframe을 해당 카드에서 재생. 외부 재생 차단 영상은 원문 링크 사용. 이미지·iframe 주소는 검증한 영상 ID로 서버/클라이언트가 구성.
- 성공한 피드 수집은 1시간 공유 캐시. 페이지 진입과 열린 동안 타이머가 서버 수집을 확인하며, 다시 창에 포커스할 때 1시간이 지났으면 확인. 닫힌 사이트를 무인으로 수집하는 크론/자동화는 연결하지 않았음.
- 피드별 D1 30초 수집 잠금으로 중복 요청 방지. 한 요청에서 최대 6개 피드를 3개씩 수집하고 남은 피드는 5초 후 다음 배치 확인. 오류는 관리자에 표시하고 이전 영상을 유지하며 5분 뒤부터 재시도 가능.
- 피드 최대 60개, 소스별 최신 120개 영상 유지, 국가별 조회 최대 360개 후 중복 제거. XML은 1.5MB, 10초 제한. YouTube 외 호스트·비HTTPS·자격증명·비표준 포트 거절, 리디렉션 자동 추적 안 함, DTD/엔티티 선언 거절.

## 검증

```
node --experimental-strip-types --loader ./scripts/capacity-check/dopamine-loader.mjs ./scripts/capacity-check/dopamine.mjs
```

Node 24의 독립 메모리 SQLite에 실제 마이그레이션을 적용. 실제 수집·목록·관리자 API 코드를 호출하고 YouTube 응답·인증 헤더만 모의 처리. 피드 주소 검증, Shorts 분류, 3개 교차 배치, 동시 수집 1회, 1시간 재사용, 국가별 분리, 분류 교정 보존, 실패 시 이전 영상 유지, 관리자 권한·CSRF·등록/중복/숨김/충돌/삭제 검사 통과. TypeScript와 production build 검사. 실제 YouTube 네트워크 수집·브라우저 iframe 재생은 이 로컬 테스트에 포함되지 않음.
